StreamMaster

Otomatisasi streaming musik live 24/7 ke YouTube.

Tentang Aplikasi

StreamMaster adalah aplikasi otomasi yang menjalankan siaran (live stream) musik secara terus-menerus 24 jam sehari, 7 hari seminggu ke kanal YouTube. Aplikasi ini:

  • Menjadwalkan dan memulai siaran live dari koleksi video musik secara otomatis.
  • Mengunggah (publish) video ke kanal YouTube sesuai jadwal.
  • Mengelola judul, deskripsi, tag, dan thumbnail siaran.

Aplikasi ini dijalankan dan dikelola oleh pemilik kanal untuk keperluan kanalnya sendiri.

Data yang Diakses

Aplikasi menggunakan API YouTube Data API v3 dengan izin akun yang menghubungkan aplikasi, untuk:

  • Membuat, memperbarui, dan mengelola siaran live serta video di kanal.
  • Mengunggah video dan memperbarui metadata (judul, deskripsi, tag, thumbnail).
  • Membaca statistik siaran (jumlah penonton, suka, komentar) untuk laporan.

Data hanya digunakan untuk menjalankan fungsi aplikasi di atas pada kanal milik pengguna. Aplikasi tidak menjual, membagikan, atau menggunakan data untuk tujuan lain.
