Kebijakan Privasi

Terakhir diperbarui: 7 September 2026

1. Pengantar

StreamMaster ("Aplikasi") adalah aplikasi otomasi streaming musik live yang dikelola oleh pemilik kanal untuk kanalnya sendiri. Kebijakan ini menjelaskan bagaimana Aplikasi mengakses, menggunakan, menyimpan, dan membagikan data Google pengguna.

2. Data yang Dikumpulkan

Aplikasi mengakses data berikut melalui Google API (YouTube Data API v3) setelah pengguna memberikan izin:

  • Informasi kanal YouTube yang terhubung (nama kanal, ID kanal).
  • Metadata video dan siaran live milik kanal (judul, deskripsi, thumbnail, jadwal).
  • Statistik siaran (jumlah penonton, suka, komentar) untuk keperluan laporan internal.

3. Penggunaan Data

Data yang diakses hanya digunakan untuk menyediakan fungsi inti Aplikasi, yaitu:

  • Menjadwalkan dan menjalankan siaran live otomatis di kanal pengguna.
  • Mengunggah video dan memperbarui metadata kanal.
  • Menampilkan laporan performa siaran kepada pemilik kanal.

4. Penyimpanan dan Keamanan Data

Token otorisasi disimpan secara lokal di server tempat Aplikasi berjalan dan tidak pernah dikirim ke pihak ketiga. Akses ke server dibatasi hanya untuk pemilik kanal.

5. Pembagian Data

Aplikasi tidak menjual, menyewakan, atau membagikan data Google pengguna kepada pihak mana pun. Data tidak digunakan untuk iklan atau pelatihan AI.

6. Kepatuhan Terhadap Kebijakan Google

Penggunaan dan transfer informasi yang diterima dari Google API oleh Aplikasi ini mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

7. Kontrol Pengguna

Pengguna dapat mencabut akses Aplikasi kapan saja melalui halaman Akun Google → Keamanan → Aplikasi pihak ketiga. Setelah akses dicabut, Aplikasi tidak dapat lagi mengakses data kanal.

8. Kontak

Pertanyaan mengenai kebijakan privasi ini dapat diajukan melalui email dukungan yang tercantum pada layar izin (consent screen) Google.
